
# Cyber - E-commerce Web Application

A modern, full-featured e-commerce application built with React 19, TypeScript, and Clerk authentication. Features a complete shopping experience with cart management and multi-step checkout.

##  Quick Start

1. **Install dependencies**
   npm install
   
   npm install @clerk/clerk-react

2. **Environment Setup**
   Create a `.env` file with:
   VITE_URL_API=http://localhost:7777
   VITE_CLERK_PUBLISHABLE_KEY=pk_test_aG9wZWZ1bC13YWxsZXllLTQuY2xlcmsuYWNjb3VudHMuZGV2JA
   ```

3. **Start development server**
   give a cd vite and tab to complete and run this command on terminal *npm run dev*

4. **Open browser**
   Visit `http://localhost:5173`

## Backend Required

Requires the `cyber-web-back` APP running on `http://localhost:7777` for full functionality.
